# مغامراتي البيئية

تطبيق تعليمي تفاعلي للأطفال عن بيئة سلطنة عُمان. يفتح الطفل خريطة عُمان، فيختار منها مغامرة يقرّر فيها بنفسه، ويجرّب كلمات بيئية تتحرّك بين يديه، ويجمع أوسمة حُرّاس البيئة. يرافقه في ذلك كلّه **الجدّ سالم**.

النصوص كلها مشكولة بالحركات لتناسب القارئ الصغير، والواجهة من اليمين إلى اليسار.

**تصميم وإعداد:** أ. عائشة البروانية

**الموقع:** https://aishaabdullh1998-ui.github.io/Beah/

---

## ما الذي يحتويه التطبيق

**خريطة عُمان.** الشاشة الرئيسية خريطة، وكل مغامرة تقع في موقعها الحقيقي: الجبل الأخضر، رأس الحدّ، بحر مسقط، غابة القرم، جبال الحقف، جزر الديمانيّات، صحار، جبال ظفار، وخليج مسقط. الطفل يتعلّم الجغرافيا دون درس جغرافيا.

**تسع قصص تفاعلية.** كل قصة تُبنى على قرار الطفل، وتنتهي بوسام ونصيحة بيئية. الخيار الخاطئ لا يُعاقِب، بل يُري النتيجة ثم يعيد المحاولة.

**كلمات تتحرّك.** سبع كلمات بيئية، لكل كلمة مشهد يحرّكه الطفل بنفسه: الصنبور يقطر حتى يُغلقه، والنخلة تفرغ إن أخذ كل الرطب، والسيارة تسير بلا دخان بعد أن يركّب الشمس وماء البحر. ويضاف إليها بطاقات «افعل ولا تفعل».

**خزانة الأوسمة.** مكان يرى فيه الطفل ما جمعه وما بقي.

**أسئلة الجدّ سالم.** ثلاث مجموعات تظهر تلقائيًا بعد كل ثلاث قصص مكتملة.

**حفظ التقدّم.** يُحفظ تقدّم كل طفل باسمه داخل متصفح جهازه. لا يُرسل أي شيء إلى خادم، ولا تُجمع أي بيانات عن الأطفال.

**مخاطبة صحيحة.** يسأل التطبيق في البداية: ولد أم بنت؟ ثم يخاطب الطفل بالصيغة الصحيحة في كل نصّ، من عبارات التشجيع إلى نصائح نهايات القصص.

## تشغيل التطبيق

الموقع يُبنى ويُنشر تلقائيًا عند كل تعديل يُدفع إلى هذا الفرع. ولتشغيل النشر يدويًا: تبويب **Actions**، ثم سير العمل من القائمة الجانبية، ثم زرّ **Run workflow**.

للتشغيل على جهازك:

</div>

```bash
npm install
npm run build
npx serve .
```

<div dir="rtl">

للرفع على أي استضافة أخرى، ارفعي هذه الملفات فقط: `index.html` و`assets/app.js` و`assets/styles.css`. لا يحتاج التطبيق خادم تطبيقات ولا قاعدة بيانات.

إن نسختِ المستودع إلى حساب آخر، فعّلي صفحات GitHub فيه أولًا من **Settings** ثم **Pages**، واختاري في **Source** الخيار **GitHub Actions**.

## أين تعدّلين ماذا

الملفّ الذي تفتحينه غالبًا هو **`src/content.js`** وحده. كل النصوص فيه.

</div>

| ما تريدين تعديله | مكانه |
| --- | --- |
| القصص والمشاهد والخيارات والأوسمة | `src/content.js` ← `stories` |
| موقع القصة على الخريطة | `src/content.js` ← `mapPos` داخل كل قصة |
| أسئلة الجدّ سالم | `src/content.js` ← `quizSets` |
| الكلمات المتحرّكة ونصوصها | `src/content.js` ← `dictionaryTerms` |
| بطاقات افعل ولا تفعل | `src/content.js` ← `doDontCards` |
| عبارات التشجيع بصيغتيها | `src/content.js` ← `encouragements` |
| كلام الجدّ سالم | `src/content.js` ← `salim` |
| نصوص الأزرار وأسماء الأقسام | `src/content.js` ← `labels` و `sections` |
| الاسم والسنة في حقوق النشر | `src/content.js` ← `AUTHOR` و `COPYRIGHT_YEAR` |
| الألوان كلها | `src/theme.js` |
| شكل الجدّ سالم والخريطة والأوسمة | `src/art.jsx` |
| مشاهد الكلمات المتحرّكة | `src/scenes.jsx` |

<div dir="rtl">

بعد أي تعديل، شغّلي `npm run build` حتى تظهر التغييرات في الموقع.

## البنية التقنية

</div>

```
index.html          صفحة التطبيق
src/content.js      كل النصوص والقصص والأسئلة
src/theme.js        الألوان والخطوط والمقاسات
src/art.jsx         خريطة عُمان، الجدّ سالم، الأوسمة، الأيقونات
src/scenes.jsx      مشاهد الكلمات المتحرّكة السبعة
src/App.jsx         الشاشات والتنقّل
src/main.jsx        نقطة الدخول
docs/               قواعد صوت الجدّ سالم
assets/             الملفات المبنيّة
```

<div dir="rtl">

مبني على React، ويُحزَم بأداة esbuild في ملف واحد لا يعتمد على أي شبكة خارجية عدا خطوط جوجل. كل الرسم من صنع التطبيق نفسه: لا صور ولا مكتبات أيقونات.

## ما زال ناقصًا

الأقسام التالية موصوفة في خطة التطوير لكن كودها لم يصل بعد إلى المستودع:

- الألعاب البيئية: فرز المخلفات، البيت الذكي، التسوّق المستدام.
- قسم الحوار مع الجدّ سالم وموضوعاته الخمسة. قواعد صوته جاهزة في `docs/صوت-الجد-سالم.md`، وتنتظر النصوص.
