# مغامراتي البيئية

تطبيق تعليمي تفاعلي للأطفال عن بيئة سلطنة عُمان. يفتح الطفل خريطة عُمان، فيختار منها مغامرة يقرّر فيها بنفسه، ويلعب ألعابًا بيئية مجسّمة، ويستكشف معجمًا بصريًّا حركيًّا بين يديه. يرافقه في ذلك كلّه **الجدّ سالم**.

النصوص كلها مشكولة بالحركات لتناسب القارئ الصغير، والواجهة من اليمين إلى اليسار.

**تصميم وإعداد:** أ. عائشة البروانية

**الموقع:** https://aishaabdullh1998-ui.github.io/Beah/

---

## ما الذي يحتويه التطبيق

**خريطة عُمان.** القصص تُفتح من قائمة أزرار، ومن زرّ واحد تتحوّل إلى خريطة لعُمان تقع كل مغامرة فيها في موقعها الحقيقي: الجبل الأخضر، رأس الحدّ، بحر مسقط، غابة القرم، جبال الحقف، جزر الديمانيّات، صحار، جبال ظفار، وخليج مسقط. الطفل يتعلّم الجغرافيا دون درس جغرافيا.

**خطاب التكليف.** يفتح الطفل التطبيق فيُكلَّف رسميًّا بمهمّة «خبير بيئي متدرّب»، فيدخل الأقسام وهو يحمل صفة لا يتصفّح شاشات.

**ثلاث ألعاب بيئية.** فرز المخلّفات في حاويات مجسّمة تُفتح أغطيتها. البيت الذكي بأربعة أماكن — غرفة الجلوس والمطبخ والحمّام والصفّ المدرسي — كلٌّ منها رسمٌ مسطّح واضح بألوان مبهجة، وأجهزته تستجيب أمام عيني الطفل حين يُشغِّلها أو يُطفئها. التسوّق المستدام بأربعة أسواق — البقالة والملابس وأدوات المدرسة والألعاب — ولكل منتج رسمٌ يوضّحه على رفّه. كلها مبنيّة بـ CSS وSVG بلا أي مكتبة خارجية ولا صور خارجية، لتعمل على أجهزة المدارس.

**تسع قصص تفاعلية.** كل قصة تُبنى على قرار الطفل، وتنتهي بوسام ونصيحة بيئية. الخيار الخاطئ لا يُعاقِب، بل يُري النتيجة ثم يعيد المحاولة.

**المعجم البصري الحركي.** سبع كلمات بيئية، لكل كلمة مشهد يحرّكه الطفل بنفسه: الصنبور يقطر حتى يُغلقه، والنخلة تفرغ إن أخذ كل الرطب، والسيارة تسير بلا دخان بعد أن يركّب الشمس وماء البحر. ويضاف إليها بطاقات «افعل ولا تفعل».

**أسئلة الجدّ سالم.** ثلاث مجموعات تظهر تلقائيًا بعد كل ثلاث قصص مكتملة.

**حفظ التقدّم.** يُحفظ تقدّم كل طفل باسمه داخل متصفح جهازه. لا يُرسل أي شيء إلى خادم، ولا تُجمع أي بيانات عن الأطفال.

**مخاطبة صحيحة.** يسأل التطبيق في البداية: ولد أم بنت؟ ثم يخاطب الطفل بالصيغة الصحيحة في كل نصّ، من عبارات التشجيع إلى نصائح نهايات القصص.

## تشغيل التطبيق

الموقع يُبنى ويُنشر تلقائيًا عند كل تعديل يُدفع إلى هذا الفرع. ولتشغيل النشر يدويًا: تبويب **Actions**، ثم سير العمل من القائمة الجانبية، ثم زرّ **Run workflow**.

للتشغيل على جهازك:

</div>

```bash
npm install
npm run build
npx serve .
```

<div dir="rtl">

للرفع على أي استضافة أخرى، ارفعي هذه الملفات فقط: `index.html` و`assets/app.js` و`assets/styles.css`. لا يحتاج التطبيق خادم تطبيقات ولا قاعدة بيانات.

إن نسختِ المستودع إلى حساب آخر، فعّلي صفحات GitHub فيه أولًا من **Settings** ثم **Pages**، واختاري في **Source** الخيار **GitHub Actions**.

## أين تعدّلين ماذا

الملفّ الذي تفتحينه غالبًا هو **`src/content.js`** وحده. كل النصوص فيه.

</div>

| ما تريدين تعديله | مكانه |
| --- | --- |
| القصص والمشاهد والخيارات وأوسمة نهاياتها | `src/content.js` ← `stories` |
| موقع القصة على الخريطة | `src/content.js` ← `mapPos` داخل كل قصة |
| أسئلة الجدّ سالم | `src/content.js` ← `quizSets` |
| مصطلحات المعجم البصري ونصوصها | `src/content.js` ← `dictionaryTerms` |
| بطاقات افعل ولا تفعل | `src/content.js` ← `doDontCards` |
| مخلّفات لعبة الفرز وحاوياتها | `src/content.js` ← `wasteItems` و `wasteBins` |
| أماكن البيت الذكي وأجهزتها وتحدّياتها | `src/content.js` ← `homeRooms` |
| أسواق التسوّق المستدام واحتياجاتها | `src/content.js` ← `marketSets` |
| خطاب التكليف | `src/content.js` ← `mission` |
| عبارات التشجيع بصيغتيها | `src/content.js` ← `encouragements` |
| كلام الجدّ سالم | `src/content.js` ← `salim` |
| نصوص الأزرار وأسماء الأقسام | `src/content.js` ← `labels` و `sections` |
| الاسم والسنة في حقوق النشر | `src/content.js` ← `AUTHOR` و `COPYRIGHT_YEAR` |
| الألوان كلها | `src/theme.js` |
| شكل الجدّ سالم والخريطة وخلفيات بيئات القصص | `src/art.jsx` |
| مشاهد المعجم البصري | `src/scenes.jsx` |

<div dir="rtl">

بعد أي تعديل، شغّلي `npm run build` حتى تظهر التغييرات في الموقع.

## البنية التقنية

</div>

```
index.html          صفحة التطبيق
src/content.js      كل النصوص والقصص والأسئلة
src/theme.js        الألوان والخطوط والمقاسات
src/art.jsx         خريطة عُمان، الجدّ سالم، الأوسمة، الأيقونات
src/scenes.jsx      مشاهد المعجم البصري السبعة
src/games.jsx       الألعاب البيئية الثلاث، بأماكنها وأسواقها ورسومها
src/App.jsx         الشاشات والتنقّل
src/main.jsx        نقطة الدخول
docs/               قواعد صوت الجدّ سالم
assets/             الملفات المبنيّة
```

<div dir="rtl">

مبني على React، ويُحزَم بأداة esbuild في ملف واحد لا يعتمد على أي شبكة خارجية عدا خطوط جوجل. كل الرسم من صنع التطبيق نفسه: لا صور ولا مكتبات أيقونات.

## ما زال ناقصًا

قسم الحوار مع الجدّ سالم وموضوعاته الخمسة: عطش الباطنة، أمانة الشاطئ، دخان المصنع، شجرة اللبان الجريح، وناقلة كبيرة في بحر ظفار. قواعد صوته وبنية القسم جاهزة في `docs/صوت-الجد-سالم.md`، وتنتظر النصوص.
