# مغامراتي البيئية

تطبيق تعليمي تفاعلي للأطفال عن بيئة سلطنة عُمان. يقدّم تسع قصص يختار فيها الطفل قراراته بنفسه، ومعجمًا حركيًا يشرح المصطلحات البيئية عبر ألعاب قصيرة، واختبارات تظهر كلّما أكمل الطفل ثلاث قصص.

النصوص كلها مشكولة بالحركات لتناسب القارئ الصغير، والواجهة من اليمين إلى اليسار.

**تصميم وإعداد:** أ. عائشة البروانية

---

## ما الذي يحتويه التطبيق

**القصص التفاعلية.** تسع مغامرات من بيئات عُمانية حقيقية: الفلج في الجبل الأخضر، سلحفاة رأس الحد، التسرّب النفطي في بحر مسقط، غابة القرم، وعل جبال الحقف، صقر الديمانيات، هواء صحار، شجرة اللبان في ظفار، وخليج مسقط. كل قصة تنتهي بوسام ونصيحة بيئية.

**المعجم الحركي.** سبعة مصطلحات بيئية، لكل مصطلح لعبة قصيرة يجرّبها الطفل بنفسه: إعادة التدوير، ترشيد الماء، التنوّع الحيوي، سخونة الأرض، التلوّث، الاستدامة، والهيدروجين الأخضر. ويضاف إليها بطاقات «افعل ولا تفعل».

**الاختبارات.** ثلاث مجموعات من الأسئلة تظهر تلقائيًا بعد كل ثلاث قصص مكتملة.

**حفظ التقدّم.** يُحفظ تقدّم كل طفل باسمه داخل متصفح جهازه. لا يُرسل أي شيء إلى خادم، ولا يُجمع أي بيانات عن الأطفال.

## تشغيل التطبيق

التطبيق صفحة ويب ثابتة، تعمل على أي متصفح حديث في الحاسوب أو الهاتف دون تثبيت.

### على GitHub Pages

الموقع منشور ومتاح للجميع على:

**https://aishaabdullh1998-ui.github.io/Beah/**

يُبنى الموقع ويُنشر تلقائيًا عند كل دفعة جديدة إلى هذا الفرع. ولتشغيل النشر يدويًا في أي وقت: تبويب **Actions**، ثم سير العمل من القائمة الجانبية، ثم زر **Run workflow**.

إن نسخت هذا المستودع لحسابٍ آخر، فعّل صفحات GitHub فيه أولًا من **Settings** ثم **Pages**، واختر في **Source** الخيار **GitHub Actions**، لأن صلاحيات سير العمل لا تكفي لتفعيلها بنفسه.

### على جهازك

</div>

```bash
npm install
npm run build
npx serve .        # أو أي خادم ملفات ثابتة
```

<div dir="rtl">

يكفي بعد ذلك فتح `index.html` عبر الخادم المحلي.

### على أي استضافة أخرى

ارفع هذه الملفات فقط: `index.html` و`assets/app.js` و`assets/styles.css`. لا يحتاج التطبيق إلى خادم تطبيقات ولا قاعدة بيانات.

## التعديل على المحتوى

كل المحتوى في ملف واحد هو `src/App.jsx`:

</div>

| ما تريد تعديله | مكانه في الملف |
| --- | --- |
| القصص والمشاهد والخيارات | المصفوفة `stories` |
| أسئلة الاختبارات | المصفوفة `quizSets` |
| مصطلحات المعجم | المصفوفة `dictionaryTerms` |
| بطاقات افعل ولا تفعل | المصفوفة `doDontCards` |
| عبارات التشجيع | المصفوفة `encouragements` |
| الألوان والخطوط | الثوابت في أعلى الملف |

<div dir="rtl">

بعد أي تعديل، أعد البناء بأمر `npm run build` حتى تظهر التغييرات في الموقع.

## البنية التقنية

</div>

```
index.html              صفحة التطبيق
src/App.jsx             الكود والمحتوى كاملًا
src/main.jsx            نقطة الدخول
src/input.css           مدخل Tailwind
assets/app.js           الحزمة المبنيّة (React + lucide مضمّنان)
assets/styles.css       أنماط Tailwind المبنيّة
.github/workflows/      سير عمل النشر التلقائي
```

<div dir="rtl">

مبني على React مع أيقونات lucide وأنماط Tailwind، ويُحزَم بأداة esbuild في ملف واحد لا يعتمد على أي شبكة خارجية عدا خطوط جوجل.
